Video Page

This page can also work as a simple photo gallery.

A page name can stay the same while the content changes. Later, real videos can be added with iframe embeds, but for now this page shows selected photos from the collection.

Why not all photos?

Several images were very similar, so only a smaller set was kept to make the site cleaner.

How to add more later

Copy another file into the images folder and then add a new img tag in the page.

How to add real videos

Replace one photo card with an embedded video using the HTML iframe tag.
